Política de Privacidade

Última atualização: 23 de novembro de 2026.

O que é recolhido

Quando o utilizador autoriza a sua conta TikTok, o Clipfac recebe do TikTok um token de acesso e um token de renovação, e lê o nome de utilizador e as opções de publicação da conta (privacidades permitidas e duração máxima dos vídeos).

Onde fica

Tudo é guardado apenas no computador do utilizador. O Clipfac não tem servidor próprio e não envia dados a terceiros: comunica só com a API do TikTok, para publicar os vídeos que o utilizador escolheu.

Como apagar

Apagar a pasta .tiktok do projeto remove os tokens. A autorização também pode ser retirada nas definições da conta TikTok (Segurança > Gerir apps).

Contacto

Através de github.com/alexmdasilva.

Privacy Policy

Last updated: November 23, 2026.

When a user authorizes their TikTok account, Clipfac receives an access token and a refresh token from TikTok and reads the account's username and posting options. All of it is stored only on the user's own computer. Clipfac has no server and shares no data with third parties; it talks only to the TikTok API, to post the videos the user chose. Deleting the project's .tiktok folder removes the tokens, and access can be revoked in the TikTok account settings. Contact: github.com/alexmdasilva.
